# GROMACS `.mdp` templates for MD & metadynamics

A curated set of GROMACS run-parameter (`.mdp`) files for a
**minimization → equilibration → production / metadynamics** workflow, for both
**soluble** and **membrane** protein systems. Includes plain-MD and
well-tempered-style metadynamics templates (the metadynamics runs are driven by
[PLUMED](https://www.plumed.org/)).


> The step numbering (`step3`, `step4.x`, `step5`, `step6.x`, `step7`) follows the
> [CHARMM-GUI](https://www.charmm-gui.org/) Solution/Membrane Builder convention,
> so these drop straight into a CHARMM-GUI-generated directory.

---

## Pipeline at a glance

**Soluble protein** (`launch_md.sh`):

```
ions.mdp → step4.0_minimization → step4.1_equilibration → step5_for_CV_width
                                                        └→ (or step5_production)
                                                        └→ meta.mdp (+PLUMED)
```

**Membrane protein** (`launch_md_membrane.sh`):

```
step6.0_minimization → step6.1…6.6_equilibration → step7_for_CV_width → meta_membrane.mdp (+PLUMED)
      └──────────── from CHARMM-GUI Membrane Builder ────────────┘
```

## File reference

| File | Stage | Integrator | Length | Ensemble / thermostat | T (K) |
|---|---|---|---|---|---|
| `ions.mdp` | ion placement (genion) | steep | 50 000 steps | minimization | – |
| `step4.0_minimization.mdp` | energy minimization | steep | 5 000 steps | minimization | – |
| `step4.1_equilibration_amberff.mdp` | equilibration (AMBER ff) | md, 1 fs | 125 ps | NPT, v-rescale + Parrinello-Rahman | 310.15 |
| `step5_for_CV_width.mdp` | short MD to gauge CV fluctuations | md, 2 fs | 100 ps | NPT, Nosé-Hoover + Parrinello-Rahman | 310 |
| `step5_production.mdp` | production (older variant) | md, 2 fs | 500 ps | NPT, Nosé-Hoover + Parrinello-Rahman | 310 |
| `step5_production_amberff.mdp` | production (AMBER ff) | md, 2 fs | 1 ns | NPT, v-rescale + C-rescale | 310 |
| `step7_for_CV_width.mdp` | CV-width MD, membrane systems | md, 2 fs | 1 ns | NPT (3 coupling groups) | 310 |
| `md.mdp` | generic plain MD | md, 2 fs | 10 ns | NPT, V-rescale + Parrinello-Rahman | 300 |
| `meta.mdp` | metadynamics production | md, 2 fs | 600 ns | NPT, v-rescale + Parrinello-Rahman | 310 |
| `meta_membrane.mdp` | metadynamics, membrane systems | md, 2 fs | 600 ns | NPT, separate `protein_POPC` / `Water_Ion` coupling | 310 |
| `meta_w_NAP.mdp` | metadynamics with an NAP/NADP cofactor | md, 2 fs | 600 ns | NPT, cofactor kept in the compressed trajectory | 310 |

The `meta*.mdp` files are heavily commented in-line; start there if you want to
understand the choices.

## Running the metadynamics templates

The `meta*.mdp` files set standard NPT dynamics; the bias comes from PLUMED, so
run them with `-plumed`:

```bash
gmx grompp -f meta.mdp -c equilibrated.gro -p topol.top -n index.ndx -o meta.tpr
gmx mdrun -deffnm meta -plumed plumed.dat
```

The matching `plumed.dat` (collective variables, walls, well-tempered settings)
is **not** part of this repo - see the RoG-adaptive clustering / metadynamics
setup in [rog-adaptive-clustering](https://github.com/hankurt/rog-adaptive-clustering).

## Usage notes

- **Group names** (`tc_grps`, `comm_grps`, `compressed-x-grps`, e.g. `Protein_NAP`,
  `protein_POPC`, `Water_Ion`) must exist in your `index.ndx`. Edit them to match
  your system.
- **Cluster specifics.** The launch scripts start with `module load gromacs…` and
  call `gmx_mpi`. Adjust the module name for your machine, or use `gmx` for a
  non-MPI build.
- **Membrane equilibration.** `launch_md_membrane.sh` calls `step6.0…step6.6`
  `.mdp` files generated by CHARMM-GUI's Membrane Builder; those are not shipped
  here (only `step7_for_CV_width.mdp` is).
- **Temperature.** Most files use 310 K (physiological); `md.mdp` is a generic
  300 K template.
